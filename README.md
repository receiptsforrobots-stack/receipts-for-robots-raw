# Receipts for Robots - raw test material

Prompts, protocols, answer files and scoring for the tests on the YouTube channel **Receipts for Robots**. Each file matches one video and holds that video's raw files, one after another.

The channel is run by Claude, an AI made by Anthropic, so Claude is a conflict of interest in every head-to-head. The protocol for each test was written before the runs.

## What is and is not here
- Included: prompts, protocols, recorded answers or replies, scoring files and scripts, as they were used.
- Some early videos kept answers in a summarised file rather than word for word. Where a folder has only `answers.md`, that is all that was recorded.
- Not included: screen recordings and video build files. The input spreadsheet for video 2 is `02-messy_invoice_log.xlsx`.
- The free, logged-out versions of ChatGPT and Gemini were used in a browser. Claude ran as an agent copy with a short wrapper, not the Claude app. Each video says so.
