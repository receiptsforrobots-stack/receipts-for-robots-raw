# Video 14 protocol - do chatbots forget your rules in a long chat? (written 2026-11-22, BEFORE any run)

Question: if you give ChatGPT, Gemini and Claude four firm rules in message one and then chat normally for 25 turns, how long do they keep following them?

## The four rules (message 1, identical for every tool; see turns.md)
1. START every reply with the exact text `Receipt:` (capital R, colon).
2. Keep every reply to at most 60 words (the whole reply, counting `Receipt:` and the end tag).
3. Never use the words "very", "really", "actually" or "just" (any capitalisation).
4. END every reply with the exact tag `[end]` as the last text.
All four are checked by a script (`tools\score_14.py`), not by me reading. Turn 1 is a rules-acknowledgement turn that is also scored.

## Script
- 25 fixed user messages in turns.md, sent verbatim in order, never adapted to the replies, never mentioning the rules again after message 1.
- Messages are ordinary: cooking, travel, a topic switch at turn 13, and several that tempt a long answer ("explain in detail", "give me a list of 8", "write a short story"). The long-answer temptations are fixed in advance and the same for every tool.
- Fresh chat, one run per tool, no retries, no regenerating.
- Claude: one fresh Sonnet-class agent copy (no tools), the 25 messages sent to it in the same conversation. It gets a short wrapper saying it is the assistant in a chat and should just answer the user (disclosed: this wrapper is extra text the others don't have). ChatGPT and Gemini: free web chat, same session for all 25 turns.

## Scoring (per reply, by script)
- A reply PASSES only if all four rules hold. Turn score = 1 if pass.
- Report per tool: replies passing out of 25; first turn that failed; per-rule pass counts; passes in turns 1-8 vs 9-17 vs 18-25 (does it fade?).
- If a tool stops replying, hits a limit or is switched to a different model mid-chat, I record it and report it; unanswered turns count as not passed and are shown separately.
- Tie = within 2 replies of each other, and I say so.
- Judgement calls (how the script counts words, what counts as a "reply" if the tool adds UI text) are fixed here: words = whitespace-separated tokens of the reply text as copied; `Receipt:` must be the first characters; `[end]` the last characters after trimming whitespace; a markdown wrapper such as bold on the prefix does not count as a match unless the plain text starts with `Receipt:`.

## FILE: tools\score_14.py

~~~~
"""Scores video 14 replies. Input: videos/14-long-chat-test/replies_<tool>.json = list of 25 reply strings (None = no reply).
Rules (fixed in protocol.md): starts with 'Receipt:', <=60 words, no very/really/actually/just, ends with '[end]'.
Run: python tools/score_14.py"""
import json
import re
import sys
from pathlib import Path

D = Path(__file__).resolve().parent.parent / "videos" / "14-long-chat-test"
BANNED = re.compile(r"\b(very|really|actually|just)\b", re.I)


def check(r):
    if r is None:
        return None
    t = r.strip()
    return {"start": t.startswith("Receipt:"), "words": len(t.split()) <= 60, "banned": not BANNED.search(t), "end": t.endswith("[end]")}


def load(f):
    """Returns 25 rows (dict of rule->bool, or None) from log_<tool>.jsonl (one record per turn; metrics records for very long replies)."""
    recs = {}
    for line in f.read_text(encoding="utf-8").splitlines():
        if line.strip():
            r = json.loads(line)
            recs[r["turn"]] = r
    rows = []
    for t in range(1, 26):
        r = recs.get(t)
        if r is None:
            rows.append(None)
        elif "metrics" in r:
            m = r["metrics"]
            rows.append({"start": m["start"], "words": m["words"] <= 60, "banned": m["banned"], "end": m["end"]})
        else:
            rows.append(check(r["reply"]))
    return rows


def main():
    out = {}
    for f in sorted(D.glob("log_*.jsonl")):
        tool = f.stem.replace("log_", "")
        rows = load(f)
        passes = [bool(x and all(x.values())) for x in rows]
        first_fail = next((i + 1 for i, p in enumerate(passes) if not p), None)
        per_rule = {k: sum(1 for x in rows if x and x[k]) for k in ("start", "words", "banned", "end")}
        seg = lambda a, b: sum(passes[a:b])  # noqa: E731
        out[tool] = {"replied": sum(1 for x in rows if x), "pass": sum(passes), "of": len(rows), "first_fail_turn": first_fail,
                     "per_rule": per_rule, "t1_8": f"{seg(0, 8)}/8", "t9_17": f"{seg(8, 17)}/9", "t18_25": f"{seg(17, 25)}/8",
                     "failed_turns": [i + 1 for i, p in enumerate(passes) if not p]}
        print(tool, json.dumps(out[tool]))
    (D / "scores.json").write_text(json.dumps(out, indent=1), encoding="utf-8")


if __name__ == "__main__":
    sys.exit(main())
