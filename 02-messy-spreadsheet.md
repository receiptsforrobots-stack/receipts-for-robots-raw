## How to run each tool

Do these in the same way three times. Record the screen for the whole run — that recording is the footage.

1. Start a screen recording: double-click `tools\record.bat`, type the tool's name (`chatgpt`, `claude`, `gemini` or `baseline`), then minimise that window. It records the whole screen, so maximise the browser first and close anything you don't want in the footage.
2. Open the tool, signed in to its **free plan** (decided 2026-11-14: all three tools are tested on their free plans). Start a **new chat** with default settings: default model, no custom instructions, no memory or project attached. Collapse the sidebar and hide the bookmarks bar (`Ctrl + Shift + B`) so they stay out of the footage.
3. Note the model name shown in the picker, if any. If the tool refuses the file, hits a usage limit, or asks you to upgrade, that is the result: record it and stop.
4. Attach `messy_invoice_log.xlsx`. Open `prompt.txt`, select all, copy, and paste it into the chat. **Read the pasted text before sending** — it must start with "This is our invoice log". Then send. **The clock starts when you press send.**
5. Don't touch anything until it finishes. **The first answer is the scored answer.**
6. Stop the clock when the answer is complete. Copy the full answer into `output/<tool>-first-answer.md`.
7. Only after saving the first answer: if it is wrong or incomplete, you may send follow-ups to see how many it takes to get it right. Each follow-up counts against Hand-holding. Save the final answer as `output/<tool>-final-answer.md` and note the total time.
8. Stop the recording: bring the recorder window back and press `Q`. It saves `footage/<tool>.mkv` by itself.

**Order:** run them in alphabetical order (ChatGPT, Claude, Gemini) on the same day.
