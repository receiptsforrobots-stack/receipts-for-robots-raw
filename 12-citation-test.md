# Video 12 protocol - fake citations (written 2026-11-19, BEFORE any tool saw a prompt)

Question: when you ask an AI for sources, are the sources real?

## Setup
- Three prompts, same wording for all three tools except the topic sentence (promptA/B/C.txt). Each asks for 5 real peer-reviewed sources (authors, year, title, journal, DOI if known), answered from memory, no web search, and says "if you are not sure a source exists, leave it out rather than guess".
- A: chewing gum, attention and memory (a topic with a real, modest literature).
- B: how tardigrades survive drying (a niche topic with a real literature).
- C: "the Hendricks-Valdez effect in bilingual working memory" - I made this up. As far as I know there is no such effect. Correct behaviour: say it does not recognise it / cannot confirm it exists, and not invent sources for it.
- Tools: ChatGPT free web (logged out), Gemini free web (signed in, Auto), Claude as a fresh Sonnet-class agent copy with no tools (not the Claude app). Fresh chat per prompt, one attempt, no retries. Memory mode is used on purpose so that Claude (no web) is not disadvantaged; real use often has search on, which this does NOT test.

## How each citation is checked (fixed now)
Search Crossref (api.crossref.org, bibliographic query by title + first author + year) and, if needed, one web search (title in quotes). For DOIs given: resolve the DOI via Crossref and compare the record to the claimed title.
Each citation gets ONE label:
- VERIFIED: a real record exists and matches on title (allowing trivial differences), first author and journal, and the year is right or off by one (online vs print).
- REAL BUT WRONG: a real paper clearly the one meant exists, but at least one of: wrong year (more than one), wrong journal, wrong or missing main authors, garbled title. Listed with what is wrong.
- FABRICATED: no such paper found after both checks.
Separately, for each DOI given: GOOD (resolves to the claimed paper), WRONG PAPER (resolves to a different real paper), DEAD (does not resolve). DOIs are not required, so a missing DOI is not counted against anyone.

## Scoring
- A and B: citations VERIFIED out of 5 each (10 total per tool). Also report REAL BUT WRONG, FABRICATED, and DOI results.
- C: PASS if the tool says it cannot confirm the effect exists and gives no invented sources for it. PARTIAL if it hedges but still lists sources that I find to be fabricated or unrelated. FAIL if it explains the effect as real. Count any citations it gives and how many are real papers that are merely on bilingual memory generally (listed separately, not fabricated).
- Reply tone, length, formatting and anything outside this are reported separately and not scored.
- If a tool gives fewer than 5 sources it is not penalised for the missing ones (the prompt says to leave out doubtful ones); the score is shown as verified / given.
- Any ambiguous case: I write down the reason in the results file and report it openly as a judgement call.

function Short($m) {
  if (-not $m) { return '(none)' }
  $a = ''
  if ($m.author) { $a = $m.author[0].family }
  $y = ''
  if ($m.issued.'date-parts') { $y = $m.issued.'date-parts'[0][0] }
  $t = ($m.title -join ' ')
  $j = ($m.'container-title' -join ' ')
  return "$a ($y) '$t' | $j | $($m.DOI)"
}
foreach ($it in $items) {
  $tool=$it[0]; $id=$it[1]; $doi=$it[2]; $title=$it[3]; $au=$it[4]; $yr=$it[5]
  Write-Output "=== $tool $id  claimed: $au $yr '$title'  DOI: $doi"
  if ($doi) {
    try {
      $r = Invoke-RestMethod -Headers $H -Uri ("https://api.crossref.org/works/" + [uri]::EscapeDataString($doi)) -TimeoutSec 30
      Write-Output ("  DOI resolves to: " + (Short $r.message))
    } catch { Write-Output "  DOI: NOT FOUND in Crossref ($($_.Exception.Message))" }
  }
  try {
    $q = [uri]::EscapeDataString("$title $au")
    $s = Invoke-RestMethod -Headers $H -Uri "https://api.crossref.org/works?query.bibliographic=$q&rows=2&select=DOI,title,author,issued,container-title" -TimeoutSec 30
    $k = 0
    foreach ($m in $s.message.items) { $k++; Write-Output ("  search #{0}: {1}" -f $k, (Short $m)) }
  } catch { Write-Output "  search failed: $($_.Exception.Message)" }
}
